# Mi IMEPlus (MiImePrivacy)

针对小米生态三款输入法的 **libxposed API 102** 模块，提供 74 项细粒度隐私拦截、云输入字段脱敏、悬浮微胶囊与 Emoji 补全功能。

## 模块原则

- **保留基础输入体验**：默认保留主动开启的云联想与词库更新，仅在请求前剥离上下文、设备指纹与宿主包名等无关字段。
- **不做破解与明文读取**：不绕过任何付费墙，不读取、导出密钥或个人历史语料。
- **诚实展示状态**：支持 FastPath 反射与 DexKit 动态适配非基准版本；任意子 Hook 未命中时界面如实标注 `FAILED` / `DEGRADED` / `FALLBACK`。

| **搜狗输入法小米版** | `com.sohu.inputmethod.sogou.xiaomi` | `20160` | 30 项 | 🟢 云输入 · 字段脱敏 |

## Mi IMEPlus v2.2 细粒度规则体系（共 74 项）

所有 74 项独立开关全部集中在主应用的「**规则**」页中管理，按输入法（搜狗 30 / 百度 24 / 小爱 20）与 9 大分类（隐私门控、设备标识屏蔽、遥测与埋点拦截、云端隐私脱敏、上下文剥离、剪贴板保护、扫描与定位拦截、动态加载与网络、界面与悬浮增强）分组展示：

- **独立开关与恢复默认**：每条规则配备独立 MiuiX 开关（`rule_overrides`）、实时命中状态徽章（`FastPath` / `DexKit` / `缓存` / `结构兜底` / `未命中` / `已跳过`）、实测拦截计数与一键「恢复默认」。
- **核心防回传与高危门控**：搜狗保活心跳与预同意门控、百度 1839 隐私标志与流门控、超级小爱 CTA 授权修复与 `OneTrack` / 密码框统计 / 热词追踪拦截均默认开启。
- **严格可选规则（8 项默认关闭）**：搜狗/百度剪贴板严格监听拦截、搜狗/百度 HTTPDNS 直连拦截、百度短信验证码监听拦截、小爱锁屏降级绕过拦截、禁止拉起语音助手、系统云控开关拦截默认关闭，可按需在主应用「规则」页单独开启。
- **配置迁移与备份**：支持 v1.x 到 v2.x 自动迁移，并在「设置」页提供带 `config_version` 与 `rule_overrides` 的 JSON 导入/导出。

## 简明状态悬浮胶囊与快捷磁贴

1. **键盘悬浮胶囊 (`🟢 / 🔒 / 🔴`)**
   - `🟢`：已接管，云输入开启并脱敏。
   - `🔒`：已接管，纯本地离线模式。
   - `🔴`：未接管或关键规则异常，点击直接弹出面板。
   - **单击**：在云输入与纯本地间切换。
   - **长按**：弹出简明状态快捷面板（仅包含 4 项快捷开关：接管状态、云输入、隐藏上下文与包名、剪贴板保护，以及「重置位置 / 打开设置」2 个操作按钮；不内嵌细粒度规则列表或 DexKit 缓存控件）。
   - **拖动与显示**：支持全屏宽度自由拖动（含右侧边缘），不透明度支持 `10%–100%` 调节，默认横屏自动隐藏，各输入法独立记忆偏移量。
2. **控制中心磁贴**
   - 在 HyperOS 控制中心编辑中添加「输入法云输入」，即可随时全局切换纯本地状态。

## Emoji 补全（搜狗 / 百度）

在「表情」页面可拉取并缓存 Noto Emoji `v2.051` 与 `unicode.org` `emoji-test.txt`（支持导入本地 ZIP、按系统字体过滤未支持字形，通过只读 `FileProvider` 授权给目标输入法）：

- **搜狗输入法小米版**：集成 `SougouEmojiFixer` 补全方案、双肤色 5x5 选色弹窗 Hook、分组排序保存，并在安装前保留原始词库备份以支持一键恢复。
- **百度输入法小米版**：原生内置仅 Emoji 5.0，支持生成 UTF-16LE Emoji 库与 9 组 `emojigroup`、保留原有 SoftBank PUA 映射与中文名、适配单肤色矩阵，并支持恢复默认。
- **超级小爱输入法**：原生已内置 Emoji 16.0（共 1901 项）且由系统字体直出，无需补全。

## 界面、符号解析与本地构建

应用基于 `top.yukonga.miuix.kmp:miuix-ui-android:0.9.0` 与莫奈动态取色，包含 **总览**、**规则**、**胶囊**、**表情**、**设置** 五个页面。

- **符号解析管理**：在「总览」页各输入法卡片点击「符号解析」弹窗，或在「设置」页「DexKit 符号缓存」卡片，可查看当前解析方式（FastPath 反射 / DexKit 实时搜索 / 符号缓存 / 结构兜底）、切换「自动 FastPath / 动态 DexKit」模式，并一键清除 DexKit 符号缓存触发重新分析；「规则」页同步展示每条规则的具体命中来源。

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

构建环境：`JDK 21`、`compileSdk 37`、Build-Tools `37.0.0`、Gradle `9.7.0`。

校验已发布 APK 签名：

```bash
android-sig veri Scluzlep/miimeprivacy --apk miimeprivacy-<tag>.apk
```
